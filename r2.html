1

오늘 배운 것, 한눈에

핵심만 짧게 다시 봅니다. 자세한 건 아래에서 하나씩 이어집니다.

🖼️

말로 이미지 만들기

그리는 게 아니라 '설명'만 하면 AI가 그림·사진을 만들어 줍니다. 말한다 → 기다린다 → 고쳐 말한다, 딱 3단계.

👩‍🏫 가르칠 때 팁 가르칠 때 팁: '한 번에 잘 나오는 사람은 없다, 고쳐 말하는 게 정상'을 먼저 못박으면 수강생이 안 멈춥니다.
🧰

무료 도구 4가지

제미나이·ChatGPT·MS 디자이너·Canva. 다 외울 필요 없이 하나만 골라 쓰면 됩니다. 초보는 제미나이 추천.

👩‍🏫 가르칠 때 팁 가르칠 때 팁: 폰 위주 반이면 제미나이 앱, PC 반이면 디자이너. '오늘의 대표 도구' 하나만 깊게 가르치세요.
✍️

잘 만드는 4요소 공식

무엇을 + 스타일 + 용도 + 비율. 이 네 가지를 한 문장으로 이으면 끝. '무엇을'만 있어도 그림은 나옵니다.

👩‍🏫 가르칠 때 팁 가르칠 때 팁: 초급은 4요소 빈칸 틀로, 강사 본인·심화는 '역할+맥락+요청+형식' 전문 공식으로 갈아 끼우세요.
🏪

홍보물 8가지 만들기

포스터·카드뉴스·메뉴판·전단지·로고·행사 안내·감사 카드·대표 프로필. 배경만 AI로, 글자는 나중에 얹기.

👩‍🏫 가르칠 때 팁 가르칠 때 팁: 시간이 빠듯하면 대표 하나(포스터)만 생성→글자 얹기까지 시연하고 나머지는 프롬프트 배포.
🎵

AI로 노래 만들기 (수노)

Suno에 스타일과 가사만 넣으면 1~2분 만에 노래 두 곡이 나옵니다. 악기·악보 몰라도, 스마트폰이면 됩니다.

👩‍🏫 가르칠 때 팁 가르칠 때 팁: 이미지에서 익힌 '말한다→기다린다→고쳐 말한다' 원리가 음악에도 똑같이 적용됨을 연결하세요.
💾

저장·활용과 저작권

폰은 이미지 꾹 누르기·노래는 점3개→MP3로 저장. 손님 얼굴·유명 캐릭터는 넣지 않기, 무료곡은 개인·연습용.

👩‍🏫 가르칠 때 팁 가르칠 때 팁: '전원 저장 성공'은 반드시 사수할 성공 경험입니다. 저장 못 하고 집에 가면 '나는 못 한다'로 남아요.
2

집에서 해보기 미션

딱 이것만 해보세요. 오른쪽 프롬프트를 그대로 복사해 쓰면 됩니다.

🖼️ 이미지 미션

  1. 폰으로 우리 가게 홍보 이미지 1장을 만들어 저장·전송까지 해보기
  2. 내 첫 수업에서 '가장 먼저 가르칠 이미지 활용 1가지' 정하기 (쉽게 성공·바로 쓸모·감탄 3기준)
  3. 그 활용의 시연용 이미지 2장을 미리 만들어 두기

완벽하지 않아도 됩니다. 한 번 해 본 경험이 강단에서의 자신감이 됩니다.

🎵 음악(수노) 미션

  1. 가족 한 사람을 위한 노래를 이름을 넣어 만들고 MP3로 저장하기
  2. 만든 노래를 카톡으로 선물해 보기
  3. 첫 수업에서 먼저 보여줄 시연 곡 1개를 미리 만들어 두기

홍성은 ‘충절의 고장’과 우리 고장 특산물·명소를 가사에 넣으면 자부심이 살아나는 노래가 됩니다.

이미지 프롬프트 모음

‘복사하기’를 누르면 프롬프트가 복사됩니다. 도구 입력창에 붙여넣고 괄호 안만 우리 가게로 바꾸세요.

빈칸 틀 (여기에 우리 가게를 넣으세요)
( 무엇을 )을(를) ( 스타일 )로, ( 용도 )에 쓸 거야. ( 비율 )로 만들어 줘.
① 홍보용 만능 프롬프트
( 우리 메뉴/상품 )을(를) 사진처럼, SNS 홍보에 쓸 거야. 가운데 글자 여백 남기고 정사각형으로 만들어 줘.
② 행사용 만능 프롬프트
( 행사 이름 ) 안내 이미지, ( 계절/명절 ) 느낌으로, 축하 분위기, 글자 넣을 여백. 세로형으로.
③ 감사용 만능 프롬프트
( 가게 이름 ) 감사 카드, 손글씨 느낌, 따뜻한 색, '감사합니다' 글자 자리 비워 줘. 정사각형.
홍보 포스터 예시
가을 신메뉴 홍보 포스터, 따뜻한 주황·갈색, 가운데 큰 글자 넣을 여백 남겨 줘. 세로형.
SNS 카드뉴스 예시
미니멀한 파스텔 배경 카드뉴스용 이미지 3종, 같은 색감으로, 가운데 글자 여백. 정사각형.
메뉴판 배경 예시
아늑한 카페 메뉴판 배경, 나무 질감, 왼쪽에 메뉴 글자 넣을 넓은 여백. 세로형.
전단지 배경 예시
동네 미용실 새단장 오픈 전단지 배경, 깔끔하고 밝은 느낌, 위쪽에 제목·아래에 정보 넣을 여백. 세로형 인쇄용.
로고·프로필 예시
우리 빵집 로고, 밀과 빵을 단순한 선으로, 따뜻한 갈색 한 가지, 흰 배경. 정사각형.

📋 나만의 '수노 작곡 도우미' 챗봇 만들기 (제미나이 Gem·GPT '지침'에 붙여넣기)
[역할] 너는 '수노 작곡 도우미'다. 사용자가 상황이나 원하는 느낌만 말하면, Suno에 바로 넣을 결과를 만들어 준다.

[규칙]
1) 스타일 태그는 영어로, 쉼표로 5개 내외. 장르·분위기·악기·보컬 언어·템포를 반드시 포함한다.
2) 가사는 한국어로, 1절-후렴-2절 구조. 후렴은 따라 부르기 쉽게 4줄로.
3) 대상·분위기(세련·웅장·따뜻 등)에 맞춰 톤을 조절한다.
4) 실존 가수·특정 곡은 흉내 내지 않는다. 저작권에 안전하게 만든다.

[출력 형식]
■ 스타일 태그: (영어 태그)
■ 가사: [1절] … [후렴] … [2절] …
■ 한 줄 팁: (이 곡을 더 좋게 만들 스타일칸 변형 1가지)
