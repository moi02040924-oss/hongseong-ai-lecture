교육장 공용 PC, 안전하게 쓰고 나오기

교육장 PC는 여러 사람이 번갈아 씁니다. 로그인한 채로 자리를 뜨면 다음 사람이 내 이메일·사진·문서를 그대로 볼 수 있어요. 가장 먼저 내 구글 계정부터 확인하고, 아래 3가지만 몸에 익히면 어느 공용 PC에서든 안전합니다: ① 시크릿 창으로 시작 → ② 로그아웃 먼저 → ③ 기록 삭제로 마무리.

내 구글 계정 미리 확인하기 — 본인 스마트폰으로 (수업 전 필수)

교육장 PC에서 로그인하려면 내 구글 계정 이메일과 비밀번호를 알고 있어야 해요. 의외로 본인 계정을 모르시는 분이 많습니다 — 수업 전에 스마트폰으로 미리 확인해 두세요.

  • 1내 계정(이메일) 확인 — 스마트폰의 Gmail·YouTube 앱 오른쪽 위 동그란 프로필을 누르면 내 이메일(○○○@gmail.com)이 보여요. 안드로이드는 설정 → Google에서도 확인 가능.
  • 2비밀번호가 기억나면 — 수첩에 적어 안전하게 보관하세요. (공용 PC 브라우저·카톡에 저장은 금물)
  • 3비밀번호를 모르면 미리 재설정 — 스마트폰에서 설정 → Google → Google 계정 관리 → 보안 → 비밀번호 → 새 비밀번호로 변경. 또는 로그인 화면의 '비밀번호 찾기' → 스마트폰으로 오는 확인 알림·코드로 본인 확인 후 새로 설정.
  • 4계정이 아예 없으면 — 스마트폰 Gmail 앱에서 [계정 만들기](무료). 수업 당일 만들면 시간이 부족하니 꼭 미리 만들어 오세요.
📲2단계 인증을 켜 둔 분은 수업 때 본인 스마트폰을 꼭 지참하세요 — 교육장 PC에서 로그인하면 폰으로 "본인이 맞나요?" 확인 알림이 옵니다. 폰에서 '예'를 눌러야 로그인돼요.
⚠️비밀번호는 남에게 보여주지 않기 · 공용 PC에 저장하지 않기. 새로 정한 비밀번호는 잊지 않게 안전한 곳에 적어 두세요.
시크릿 창으로 크롬 시작하기

크롬 오른쪽 위 ⋮ → '새 시크릿 창' (단축키 Ctrl + Shift + N). 어두운 창이 뜨면 성공이에요. 시크릿 창은 창을 닫는 순간 방문 기록과 로그인이 자동으로 지워져서 공용 PC에 가장 안전합니다.

⚠️창의 X 버튼만 눌러 닫는 것은 로그아웃이 아닙니다. 일반 창을 썼다면 반드시 '로그아웃'을 먼저 누르세요.
구글 로그인 — 주의 2가지 지키며 로그인
  • 1google.com 접속 → 오른쪽 위 '로그인' 클릭 → 이메일 입력 후 '다음'
  • 2'로그인 상태 유지' 체크는 반드시 해제 — 켜면 다음 사람에게도 로그인이 남아요
  • 3'비밀번호를 저장하시겠어요?' 팝업이 뜨면 '저장 안 함' 클릭 — 저장하면 내 비밀번호가 이 PC에 남습니다

구글 계정은 하나의 열쇠예요. Gmail에 로그인하면 드라이브·문서·지도에도 함께 로그인되고, 로그아웃하면 전체가 함께 정리됩니다.

강사 마인드셋 3원칙 — 오늘부터 끝까지 지킬 약속
  • 1민감정보는 안 준다 — 주민번호·카드번호·고객 실명·회사 기밀은 AI 입력창에 넣지 않아요. 인터넷 검색창에 안 칠 것은 AI에도 안 칩니다.
  • 2결과는 반드시 검수한다 — AI는 '자신 있게 틀리는 인턴'이에요. 숫자·날짜·인용은 사람이 다시 확인합니다.
  • 3책임은 사람이 진다 — 최종 결과물의 책임은 AI가 아니라 그것을 쓴 사람에게 있어요. 강사는 이 원칙을 수강생에게 전합니다.

💡 이 과정은 '운전학원'과 같아요. 오늘은 시동 거는 법부터 — 이정표 두 개: 6회차 제미나이 자격, 10회차 구글 공인 제미나이 교육자 인증.

생성형 AI, 두 문장으로 이해하기
  • ①똑똑한 자동완성 — 확률로 '다음 단어'를 예측해요. 스마트폰 문자 칠 때 다음 단어 추천, 그걸 문장·문서 단위로 훨씬 똑똑하게 하는 것.
  • ②자신 있게 틀리는 인턴 — 일은 빠른데 가끔 틀린 걸 당당하게 말해요. AI는 사실을 '검색'하는 게 아니라 '그럴듯한 다음 말'을 만들기 때문에 '환각'이 생기고, 그래서 검수가 필수입니다.

🕐 활동강사필수 — 무엇: 지난 대화 기록 모아보기·검색·삭제, 기록 저장 여부 관리. 관리법: 프로필 → [활동] → 위 검색창에서 지난 대화 찾기 / 항목 옆 삭제 / '활동 저장' 끄면 기록이 남지 않아요(프라이버시 관리).
👤 개인 인텔리전스당일확인 — 무엇: 내 구글 활동(Gmail·검색 등) 기반 개인 맞춤 답변. 관리법: 프로필 → [개인 인텔리전스] → 켜기/끄기. 개인정보 연동이라 민감정보 주의, 오늘은 개념만 소개.
📥 Gemini로 메모리 가져오기당일확인 — 무엇: 기존 정보·대화를 Gemini '기억(메모리)'으로 가져와 이어서 활용. 관리법: 프로필 → [Gemini로 메모리 가져오기] → 안내에 따라 진행. 최신 기능이라 당일 화면에서 동작 재확인.
◔ 사용량 한도유료 — 무엇: 현재 요금제의 사용량·잔여량 확인. 관리법: 프로필 → [사용량 한도] → 남은 사용량 확인. 느려지거나 한도 안내가 뜨면 여기부터 확인.
🕘 예약된 작업강사필수 — 무엇: 정해진 시간에 Gemini가 자동 반복 작업(예: 매일 아침 뉴스 요약). 관리법: 프로필 → [예약된 작업] → 새 작업 예약 / 목록에서 수정·삭제. 강사 자동화 맛보기로 시연.
📋 기능당일확인 — 무엇: Gemini가 제공하는 세부 기능 목록을 한눈에 보는 곳(새로 생긴 항목). 관리법: 프로필 → [기능] → 어떤 기능이 있는지 훑어보기. 구성은 자주 바뀌니 당일 화면에서 함께 확인.
💎 Gems강사필수4회차 본편 — 무엇: 역할·지침·자료를 고정한 나만의 맞춤 AI 도우미(ChatGPT의 GPTs에 해당). 관리법: 프로필 → [Gems] → [+ 새 Gem] 만들기 / 기존 Gem 수정·삭제. 오늘은 위치만, 자세히는 4회차.
🔗 내 공개 링크 — 무엇: 내가 공유(공개)한 대화·Gem 링크 목록. 관리법: 프로필 → [내 공개 링크] → 링크 확인 / 필요 없으면 공개 해제. 공유 후 링크를 회수·관리하는 습관 들이기.
🌗 테마 — 무엇: 화면 밝게(라이트)/어둡게(다크) 전환(옆 화살표 ▶로 하위 메뉴). 관리법: 프로필 → [테마] → '밝게' 선택. 빔프로젝터·강의장에서는 밝은 테마 권장(가독성).
✨ Gemini Spark 설정당일확인 — 무엇: Gemini의 개인용 AI 에이전트 'Spark' 관련 설정(새로 생긴 항목, 일부 요금제·지역부터 순차 제공). 관리법: 프로필 → [Gemini Spark 설정] → 제공 여부·설정 항목을 당일 화면에서 확인.

프롬프트 기본기 — 잘 시키면 잘하고, 대충 시키면 대충 합니다

프롬프트 = AI에게 시키는 '말'. 잘 시키는 공식은 딱 4개 — 역할 · 맥락 · 지시 · 형식. 식당 주문 비유: '떡볶이 주세요'만 하면 매운 게 나올 수 있죠. 역할("주방장님") + 맥락("아이가 매운 걸 못 먹어요") + 지시("떡볶이 하나") + 형식("안 맵게, 반만") — 4개를 다 말하면 원하는 게 정확히 나옵니다. 하나만 빠져도 엉뚱한 답이 나와요.

4요소 완성형 프롬프트 따라하기 + 🟡 내 것으로 바꾸기 (5분)

아래 프롬프트를 복사해 실행하고, 대괄호 4개가 각각 무슨 역할인지 확인하세요. 그다음 [맥락]과 [지시]를 '내 업무·일상'으로 바꿔 다시 입력합니다. 예) 학원 원장 → '학부모 안내 문자', 공방 → '체험 클래스 모집글'. 완료 기준: 4개 대괄호가 모두 들어갔는지 옆 사람과 확인.

[맥락] 나는 우리 동네에서 작은 반찬가게를 운영하는 사장이고, 단골을 늘리고 싶어.
[지시] 우리 가게 SNS에 올릴 홍보 문구를 만들어 줘.
[형식] 정중한 존댓말로, 20자 이내 3개, 각 문구 끝에 어울리는 이모지 1개.
